# Data-First Checklist — before any conclusion is written

Copy this into a new file, fill it, delete nothing structural — if a
section does not apply, write "Not applicable, because…" rather than
deleting it.

## 1. Question and scope
- Question in one sentence:
- Company / instrument / market (exchange always stated):
- Period covered (as-of date):
- What this note will NOT claim:

## 2. Source, licence, and freshness check
- Source publisher for each dataset used (or TO VERIFY):
- Licence / terms for reuse (or UNKNOWN — do not assume permission):
- Date retrieved, and last date contained in the data:
- Is any figure paywalled, scraped, or second-hand? If so, how is it
  labelled on the page that uses it?

## 3. Every number: source + period
- Figure | Source + page/section | Period | Status (verified / TO VERIFY):
- Any number without a source on this page is struck from the
  conclusion until sourced.

## 4. Confirmation before pattern
- Volume / liquidity check (where applicable):
- Trend-strength or second confirmation (where applicable):
- What would make this pattern noise rather than signal:

## 5. Downside and falsifier
- Bear case in one paragraph:
- What would change the conclusion (one falsifier, stated plainly):

## 6. Labelling
- Status: Inputs only / In progress / Completed (exactly one):
- Recommendation: none — this template never carries a buy, sell, or
  hold label, and no guaranteed return is stated or implied.
