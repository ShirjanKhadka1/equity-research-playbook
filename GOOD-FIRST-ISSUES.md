# Good First Issues

Small, well-scoped tasks a new contributor can pick up. This is a list, not
a promise: no maintainer response time is promised, and no GitHub issue has
been created for these items. Open an issue first and ask to be assigned
before starting, so two people do not do the same task.

## 1. Add an explicit falsifier section to one template

The playbook's standard is "say what would change your mind", and
`templates/data-first-checklist.md` already has a "Downside and falsifier"
section. Three templates do not yet have an explicit falsifier section of
their own — add one to exactly one template per contribution, in that
template's own voice:

- `templates/forensic-checklist.md` — what single finding would turn a
  "Flagged" verdict back to "Watch" or "Clean", and what document would
  prove it.
- `templates/earnings-review.md` — what single number next quarter would
  change the stated thesis impact (strengthen / weaken / unchanged).
- `templates/valuation-sanity-check.md` — what single fact would break
  the "if this price is right, then…" test in section 5.

Acceptance: one template per contribution; no existing section is deleted
or rewritten; the new section asks for one falsifier, stated plainly, not
a general "risks" list.

## House rules

Research only, not investment advice; never a buy/sell recommendation.
No credentials, no private data, no paywalled scraping.
